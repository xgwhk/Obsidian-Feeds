# Organize Your 3D Print Files with PrintStash

<p><img src="https://img.youtube.com/vi/htEysx3edq8/maxresdefault.jpg" alt="Hero image" /></p>If your 3D printing folder is full of STL files, 3MF files, ZIP archives, and models you've downloaded over the years, PrintStash gives you a much better way to organize them. In this video, I'll show you how to install PrintStash on Unraid, configure the API and frontend containers, connect an existing 3D model library, and have PrintStash automatically scan and organize your files. We'll create the custom Docker network, generate the JWT secret, configure the PrintStash API and frontend, complete the initial setup, and add an existing Unraid share as a Shared Volume. Best of all, you don't have to move your existing models into a new folder structure. PrintStash can index the files where they already live. Commands used in the video: Create the PrintStash Docker network: docker network create printstash Generate a JWT secret: openssl rand -hex 32 Example model mapping: Host Path: /mnt/user/data/3d-prints Container Path: /mnt/models Change the Host Path to wherever your own 3D-print files are stored.
